# 📱 Tiar Boutique - طيار بوتيك

> متجر إلكتروني تجاري متكامل ومتقدم مخصص للسوق الجزائري (e-Commerce & COD System)، مبني بأحدث التقنيات ومرتبط بنظام التوصيل والشحن **EasyAndSpeed** وقاعدة بيانات **Supabase** ونظام ذكي لمراقبة الزوار وتحسين معدل التحويل (CRO).

---

## 🌟 أبرز المميزات والخصائص المتكاملة

### 1. 🛍️ تجربة مستخدم وتحسين التحويل (High-Converting UI/UX & CRO)
- **زر الشراء العائم للهاتف (Sticky Mobile CTA):** شريط سفلي ثابت يظهر تلقائياً على أجهزة الهاتف يحتوي على السعر وزر الطلب الفوري لتسهيل الشراء دون الحاجة للتمرير.
- **إشعارات الشراء الحي (Live Sales Notifications):** نوافذ تفاعلية متحركة تُظهر عمليات الشراء المؤكدة لحظياً من مختلف ولايات الجزائر لتعزيز الإثبات الاجتماعي (Social Proof).
- **معرض تجارب وتقييمات العملاء (Verified Customer Reviews):** قسم موثق يضم آراء وتقييمات حقيقية لزبائن استلموا طرودهم في وهران، الجزائر، سطيف، باتنة وغيرها.
- **عناصر الندرة والاستعجال (Scarcity & Urgency):** مؤشر كمية المخزون المتبقية مع **عداد تنازلي حي** لانتهاء العروض الخاصة.
- **ضمان المعاينة قبل الدفع (Inspection Guarantee):** شارة بارزة تؤكد للزبون حقه في فتح العلبة وفحص الطلب أمام الموزع قبل دفع أي مبلغ (COD).
- **صفحة تتبع الشحنة الذاتية للزبون (`/track`):** مسار مباشر يمكن للزبون من خلاله إدخال رقم هاتفه أو رقم طلبه لمتابعة مسار الشحن (تم الاستلام ➔ تم التأكيد ➔ قيد الشحن ➔ تم التسليم).

---

### 2. 🚚 الربط الشامل مع شركة التوصيل (EasyAndSpeed / Yalidine Integration)
- **دعم ولايات الجزائر الـ 58:** ترقيم وتسمية معيارية بجميع اللغات (`01 - أدرار` إلى `58 - المنيعة`).
- **حساب تلقائي لرسوم التوصيل:** حساب دقيق لرسوم التوصيل لباب المنزل أو الاستلام من المكتب لكل ولاية وبلدية.
- **تأكيد الطلبات وتوليد بوليصة الشحن:**
  - زر **تأكيد EasyAndSpeed**: يقوم بإنشاء الطرد فورياً في نظام شركة التوصيل واستخراج كود التتبع (`Tracking`).
  - زر **تأكيد يدوي**: لإدارة الشحنات التي تُسلم محلياً أو خارج نظام الـ API.
- **كشف الطلبات المكررة والوهمية (Anti-Fraud):** وسم تحذيري فوري `⚠️ مكرر` لأي رقم هاتف يكرر الطلب لتفادي حجز طرود مكررة.

---

### 3. 💬 نظام استرجاع السلات المتروكة (WhatsApp CRM Recovery)
- **التقاط البيانات الفوري والشامل:** حفظ الاسم، الهاتف الأساسي، الهاتف الاحتياطي، الولاية، البلدية، والعنوان لحظياً مع كل حرف يُكتب.
- **مراسلة واتساب واتصال بنقرة واحدة:** أزرار اتصال ومراسلة مخصصة لكل من الرقم الأساسي والرقم الاحتياطي.
- **قوالب رسائل تسويقية ذكية:**
  1. 🎁 **قالب التوصيل المجاني:** عرض توصيل سريع مجاني لتحفيز العميل.
  2. 💰 **قالب التخفيض الفوري (500 دج):** خصم مباشر لحفظ الطلب قبل نفاد المخزون.
  3. 💬 **قالب المساعدة والاستفسار:** رسالة دعم لطيفة للاستفسار عن أي مشكلة واجهت العميل.
- **تتبع حالة المتابعة (CRM Status):** تصنيف كل عميل ضائع (`لم يتم التواصل` / `📞 جاري التواصل` / `✅ تم استرجاع الطلب` / `❌ لم يرد`).
- **خيارات التصدير الشاملة (Multi-Format Export):**
  - 📊 **تصدير إلى Excel (CSV):** ملف إكسل بترميز UTF-8 BOM الداعم للعربية.
  - 📄 **تصدير / طباعة PDF:** تقرير رسمي منسق وجاهز للطباعة الفورية.
  - 💬 **نسخ أرقام WhatsApp الجماعية:** نسخ كافة الأرقام بنقرة واحدة لاستخدامها في الحملات الجماعية.

---

### 4. 📊 مراقبة الزوار وسجلات الأحداث الحية (Live Spy Tracker & Analytics)
- **تسجيل أحداث تفصيلي ودائم:** تتبع النقرات، الحقول، مسار الصفحات، والمنتجات المشاهدة دون حذف أو تفريغ للأرشيف (+20 مليون سجل).
- **تحليل الجلسات والمسار (Conversion Funnel):** عرض مراحل تحول الزائر من مشاهدة الصفحة إلى المنتج ثم بدء الطلب والإتمام.
- **فلترة متقدمة حسب الأيام:** تصفية السجلات حسب (`اليوم`, `7 أيام`, `30 يوم`, `90 يوم`, `كل الأرشيف الدائم`).
- **حماية كاملة ضد موانع الإعلانات (AdBlocker Immunity):** عزل سكريبتات التتبع لضمان استلام طلبات العملاء بنسبة 100%.

---

### 5. 🗺️ التوزيع الجغرافي وسحب الـ IP (Algeria Geo-Tracking)
- **استخراج الـ IP والموقع:** تحديد المدينة والولاية جغرافياً لكل زائر تلقائياً.
- **لوحة ترتيب الولايات الأكثر نشاطاً:** تحليل أكثر الولايات زيارة للمتجر لتوجيه الحملات الإعلانية الممولة بدقة.
- **مقارنة جغرافية مزدوجة:** ترتيب الولايات الأكثر طلباً وشراءً مقارنة بالولايات الأكثر زيارة وتصفحاً.

---

### 6. 🛠️ تتبع الحملات الإعلانية ومولّد الروابط (UTM & Ads Tracker)
- **إحصائيات المنصات الإعلانية:** تتبع مباشر لزيارات ومبيعات (TikTok Ads, Facebook/Instagram Ads, Google Ads, Direct).
- **أداة إنشاء روابط الإعلانات (UTM Builder):** أداة مدمجة في لوحة الإدارة لإنشاء ونسخ روابط الإعلانات المتبوعة بضغطة زر.

---

### 7. 🔔 ميزات إضافية للوحة الإدارة (Admin Enterprise Dashboard)
- **مؤشر متوسط قيمة السلة (AOV):** حساب متوسط إنفاق الزبون بالدينار الجزائري.
- **ساعات الذروة للشراء (Peak Hours):** تحديد الساعات الأكثر تفاعلاً وطلباً لجدولة الإعلانات الممولة.
- **تحليل الأجهزة والمتصفحات:** إحصائيات دقيقة بين مستخدمي Android و iPhone وأجهزة الكمبيوتر.
- **تنبيه صوتي وبصري فوري (Live Order Chime):** رنين موسيقي وتنبيه متحرك عند وصول أي طلب جديد أثناء التواجد في لوحة الإدارة (مع زر كتم/تفعيل الصوت).
- **تصدير الطلبات إلى Excel (CSV):** تصدير كامل بيانات الطلبات بضغطة زر.

---

### 8. 🔍 تحسين محركات البحث المحلي (Local SEO)
- **توليد تلقائي لملف `sitemap.xml`:** فهرسة كافة المنتجات والصفحات بلغات الموقع الثلاث.
- **ملف `robots.txt` مهيأ:** توجيه عناكب محركات البحث وتأمين مسارات الإدارة والـ APIs.

## 🔧 البنية التقنية (Tech Stack)

| التقنية | الاستخدام |
|---|---|
| **Next.js 15 (App Router)** | إطار العمل الرئيسي والخوادم عديمة الخادم (Serverless) |
| **React 19** | بناء واجهات المستخدم التفاعلية |
| **TypeScript** | البرمجة الآمنة للأنماط والبيانات |
| **Tailwind CSS 3.4** | التصميم والتنسيق العصري والمتجاوب |
| **Supabase (PostgreSQL)** | قاعدة البيانات السحابية والتخزين الدائم |
| **EasyAndSpeed API** | نظام الشحن والتوصيل الجزائري |
| **next-intl** | الترجمة متعددة اللغات (العربية، الفرنسية، الإنجليزية) |
| **Zustand** | إدارة حالة سلة التسوق المحلية |
| **Vercel** | الاستضافة والنشر السحابي المستمر (CI/CD) |

│   │   │   │   ├── products/        # إدارة وتعديل المنتجات
│   │   │   │   └── settings/        # إعدادات المتجر والبيكسلات

│   │   │   ├── order/               # صفحة الشراء المباشر
│   │   │   ├── track/               # صفحة تتبع حالة الطلب للزبون
│   │   │   └── success/             # صفحة نجاح وتأكيد الطلب
│   │   ├── api/                     # واجهات الـ Backend APIs
│   │   │   ├── orders/              # إدارة الطلبات وتتبعها
│   │   │   ├── delivery/            # ربط EasyAndSpeed والولايات والطرود
│   │   │   ├── analyze-logs/        # محرك تحليل السجلات والجلسات

│   │   │   ├── settings/            # إعدادات التوصيل

│   │   ├── robots.ts                # توليد robots.txt
│   │   ├── sitemap.ts               # توليد sitemap.xml
│   │   └── globals.css              # التنسيقات العامة
│   ├── components/                  # مكونات الواجهة (Header, StickyCTA, LiveSalesNotification, CustomerReviews)
│   ├── data/                        # البيانات المرجعية (products, wilayas, communes)
│   ├── lib/                         # دوال الربط (supabase, easyandspeed, tracker, pixels)
│   ├── i18n/                        # ملفات الترجمة (ar.json, fr.json, en.json)
│   └── types/                       # تعريفات TypeScript

├── package.json

## 🚀 التشغيل المحلي والتثبيت

```bash
# 1. تثبيت الحزم
npm install

# 2. إعداد ملف البيئة
cp .env.example .env.local

# 3. تشغيل خادم التطوير المحلي
npm run dev

# 4. بناء نسخة الإنتاج
npm run build
```

## 🔐 إعداد لوحة الإدارة (Admin Security Setup)

- يتم الوصول للوحة الإدارة عبر المسار: `/{locale}/admin?key=YOUR_ADMIN_KEY`
- يتم ضبط مفتاح الدخول وكلمة المرور عبر متغيرات البيئة السرية في ملف `.env.local` أو في إعدادات الاستضافة:
  ```env
  NEXT_PUBLIC_ADMIN_KEY=your_secret_admin_key
  NEXT_PUBLIC_ADMIN_PASSWORD=your_secret_password
  ```
